1. RINGKASAN & PERSYARATAN SISTEM
================================================================================

E-Surat Sekolah adalah sistem berbasis web untuk digitasi pengajuan,
penyetujuan, penandatanganan digital, dan verifikasi surat resmi sekolah.

Persyaratan Minimal:
  - Windows 10/11 dengan XAMPP terinstal (Apache + MySQL/MariaDB aktif).
  - PHP >= 8.2 (Versi teruji: PHP 8.2.12 bawaan XAMPP).
  - Composer (Dependency manager untuk Laravel).
  - Peramban web (Google Chrome, Microsoft Edge, Mozilla Firefox).

Ekstensi PHP Wajib Aktif (di file C:\xampp\php\php.ini):
  - extension=gd        (Wajib: Pemrosesan gambar QR Code & stempel)
  - extension=intl      (Wajib: Format penanggalan & karakter lokal)
  - extension=zip       (Wajib: Ekspor & impor berkas Excel)
  - extension=pdo_mysql (Wajib: Koneksi database MySQL/MariaDB)
  - extension=mbstring  (Wajib: Pemrosesan teks multibyte)
  - extension=fileinfo  (Wajib: Pengenalan jenis berkas unggahan)
  - extension=dom       (Wajib: Penanganan struktur HTML/PDF)
  - extension=openssl   (Wajib: Keamanan enkripsi)

2. INSTALASI PERTAMA KALI (ONE-TIME SETUP)
================================================================================

Lakukan langkah ini HANYA saat memasang aplikasi di komputer/server baru.
Jalankan semua perintah dari folder proyek: C:\xampp\htdocs\admin_surat-main

--- 2.1 Aktifkan Ekstensi PHP -----------------------------------------------
  1. Buka C:\xampp\php\php.ini menggunakan Notepad.
  2. Hapus tanda titik koma (;) pada baris ekstensi berikut:
       extension=gd
       extension=intl
       extension=zip
       extension=pdo_mysql
       extension=mbstring
       extension=fileinfo
       extension=dom
       extension=openssl
  3. Simpan file `php.ini`.

--- 2.2 Jalankan XAMPP ------------------------------------------------------
  1. Buka XAMPP Control Panel (C:\xampp\xampp-control.exe).
  2. Klik tombol "Start" pada modul Apache dan MySQL (pastikan indikator hijau).

--- 2.3 Install Dependency Laravel (Composer) ------------------------------
  Buka Command Prompt/PowerShell di folder proyek, jalankan:
    composer install

--- 2.4 Konfigurasi File Environment (.env) --------------------------------
  Jika file .env belum ada, salin dari .env.example:
    copy .env.example .env

  Buka file .env dan pastikan pengaturan database sebagai berikut:
      APP_NAME="E-Surat Sekolah"
      APP_ENV=local
      APP_URL=http://e-surat.local

      DB_CONNECTION=mysql
      DB_HOST=127.0.0.1
      DB_PORT=3306
      DB_DATABASE=e_surat
      DB_USERNAME=root
      DB_PASSWORD=
      DB_COLLATION=utf8mb4_general_ci

--- 2.5 Generate Application Key & Storage Link ---------------------------
    php artisan key:generate
    php artisan storage:link

--- 2.6 Buat Database & Migrasi + Seeder -----------------------------------
  1. Buka http://localhost/phpmyadmin di browser.
  2. Buat database baru bernama: e_surat (collation: utf8mb4_general_ci).
  3. Jalankan perintah migrasi dan seeder di terminal:
       php artisan migrate --seed

3. KONFIGURASI DOMAIN VIRTUALHOST (e-surat.local)
================================================================================

Agar aplikasi dapat diakses melalui URL rapi http://e-surat.local/admin:

--- 3.1 Konfigurasi VirtualHost Apache --------------------------------------
  Buka file: C:\xampp\apache\conf\extra\httpd-vhosts.conf
  ISI LENGKAP file tersebut harus seperti berikut:

    # Virtual Hosts
    # Required modules: mod_log_config

    <VirtualHost *:80>
        DocumentRoot "C:/xampp/htdocs/admin_surat-main/public"
        ServerName localhost
        ServerAlias *
        <Directory "C:/xampp/htdocs/admin_surat-main/public">
            Options FollowSymLinks Includes ExecCGI
            AllowOverride All
            Require all granted
        </Directory>
    </VirtualHost>

    <VirtualHost *:80>
        DocumentRoot "C:/xampp/htdocs/admin_surat-main/public"
        ServerName e-surat.local
        <Directory "C:/xampp/htdocs/admin_surat-main/public">
            Options FollowSymLinks Includes ExecCGI
            AllowOverride All
            Require all granted
        </Directory>
    </VirtualHost>

  PENTING:
  - VirtualHost pertama memiliki "ServerAlias *" agar menangkap SEMUA request
    termasuk akses via alamat IP dari jaringan lokal.
  - JANGAN gunakan "Options Indexes" karena akan menampilkan daftar isi folder
    (directory listing) alih-alih halaman aplikasi.

--- 3.2 Daftarkan Domain di Windows Hosts File ------------------------------
  Buka File Explorer ke: C:\xampp\htdocs\admin_surat-main
  Klik 2x (double click) file: tambah_hosts.bat
  Saat jendela konfirmasi Windows (UAC) muncul, klik YES / YA.

--- 3.3 Restart Apache ------------------------------------------------------
  Buka XAMPP Control Panel, klik tombol STOP lalu START kembali pada Apache.

4. AKSES APLIKASI DARI JARINGAN LOKAL (LAN) VIA ALAMAT IP
================================================================================

Agar aplikasi E-Surat dapat diakses dari komputer/HP lain di jaringan yang sama
(misalnya sesama WiFi kantor), ikuti langkah-langkah berikut:

--- 4.1 Cari Alamat IP Laptop Server ----------------------------------------
  1. Buka Command Prompt atau PowerShell di laptop yang menjalankan XAMPP.
  2. Ketik perintah:
       ipconfig
  3. Cari baris "IPv4 Address" pada adapter jaringan yang aktif.
     Contoh: 10.10.10.72 atau 192.168.1.100

--- 4.2 Konfigurasi Apache (httpd.conf) -------------------------------------
  Buka file: C:\xampp\apache\conf\httpd.conf
  Cari baris DocumentRoot dan Directory (sekitar baris 252), ubah menjadi:

    DocumentRoot "C:/xampp/htdocs/admin_surat-main/public"
    <Directory "C:/xampp/htdocs/admin_surat-main/public">
        Options FollowSymLinks Includes ExecCGI
        AllowOverride All
        Require all granted
    </Directory>

  PENTING: Pastikan TIDAK ada kata "Indexes" pada baris Options.

--- 4.3 Konfigurasi Apache SSL (httpd-ssl.conf) -----------------------------
  Buka file: C:\xampp\apache\conf\extra\httpd-ssl.conf
  Cari bagian <VirtualHost _default_:443> (sekitar baris 121), ubah:

    DocumentRoot "C:/xampp/htdocs/admin_surat-main/public"

  Dan tambahkan blok Directory di bawahnya (sebelum baris SSLEngine on):

    <Directory "C:/xampp/htdocs/admin_surat-main/public">
        Options FollowSymLinks Includes ExecCGI
        AllowOverride All
        Require all granted
    </Directory>

--- 4.4 Buka Windows Firewall untuk Apache ----------------------------------
  Secara default, Windows Firewall MEMBLOKIR koneksi masuk dari jaringan
  Private. Ini harus diubah agar perangkat lain bisa mengakses.

  Cara Otomatis (via PowerShell Administrator):
    1. Klik kanan Start Menu ➔ pilih "Windows PowerShell (Admin)".
    2. Jalankan perintah berikut:

       netsh advfirewall firewall set rule name="Apache HTTP Server" dir=in profile=private protocol=tcp new action=allow
       netsh advfirewall firewall set rule name="Apache HTTP Server" dir=in profile=private protocol=udp new action=allow

  Cara Manual (via Control Panel):
    1. Buka Control Panel ➔ System and Security ➔ Windows Defender Firewall.
    2. Klik "Allow an app through firewall".
    3. Cari "Apache HTTP Server", centang kolom "Private" dan "Public".
    4. Klik OK.

--- 4.5 Restart Apache & Akses ----------------------------------------------
  1. Buka XAMPP Control Panel, klik STOP lalu START kembali pada Apache.
  2. Dari perangkat lain (HP/laptop) yang terhubung jaringan yang sama,
     buka browser dan ketik:
       http://[IP_LAPTOP_SERVER]/admin
     Contoh: http://10.10.10.72/admin

--- 4.6 Update APP_URL di .env (Opsional tapi Disarankan) -------------------
  Agar link dan asset (CSS/JS) tampil benar saat diakses via IP, buka
  file .env dan ubah APP_URL:

    APP_URL=http://10.10.10.72

  Lalu bersihkan cache:
    php artisan config:clear
    php artisan cache:clear

  CATATAN: Jika Anda tetap ingin menggunakan e-surat.local di laptop server,
  biarkan APP_URL=http://e-surat.local dan perangkat lain tetap bisa
  mengakses via IP (halaman akan tetap muncul, hanya link asset mungkin
  mengarah ke e-surat.local).

5. CARA MENJALANKAN APLIKASI SETIAP HARI (QUICK START)
================================================================================

  1. Buka XAMPP Control Panel ➔ Klik Start pada Apache dan MySQL.
  2. Buka browser (Chrome/Edge/Firefox), ketik alamat:
       http://e-surat.local/admin

  Akses dari Jaringan Lokal (HP/Laptop Lain):
       http://[IP_LAPTOP_SERVER]/admin
       Contoh: http://10.10.10.72/admin

   Alternatif (Tanpa Apache VirtualHost — Menggunakan Server Bawaan):

   A. Menggunakan Laravel Artisan Serve (Disarankan untuk Pengembangan):
      Jalankan perintah ini di terminal (Command Prompt/PowerShell) folder proyek:
        php artisan serve --host=0.0.0.0 --port=8000

      PENTING TENTANG PARAMETER --host=0.0.0.0:
      - Default `php artisan serve` hanya mendengarkan di `127.0.0.1` (komputer ini saja).
      - Jika diakses dari alamat IP (misal: http://10.10.10.252:8000) atau dari HP/laptop
        lain, browser akan menampilkan error "ERR_CONNECTION_REFUSED".
      - Oleh karena itu, SELALU tambahkan `--host=0.0.0.0` agar server bisa menerima
        koneksi baik dari localhost, 127.0.0.1, maupun IP jaringan LAN/WiFi Anda.

      Alamat akses:
      - Dari laptop ini: http://localhost:8000/admin atau http://127.0.0.1:8000/admin
      - Dari HP / Perangkat LAN: http://[IP_SERVER]:8000/admin
        (Contoh: http://10.10.10.252:8000/admin)

   B. Menggunakan PHP Built-in Server + router script:
        php -S 0.0.0.0:8000 -t public server.php
      (Juga menggunakan 0.0.0.0 agar bisa diakses lewat IP jaringan).

6. KONFIGURASI & PENGGUNAAN LARAVEL REVERB (REAL-TIME WEBSOCKET)
================================================================================

E-Surat Sekolah mendukung notifikasi langsung tanpa reload (Real-Time Broadcast)
menggunakan server WebSocket Laravel Reverb.

Mode Standar vs Real-Time:
  - Mode Standar (Default) : Notifikasi otomatis tersimpan di database. User
                             melihat notifikasi saat navigasi / refresh.
  - Mode Real-Time (Reverb): Notifikasi popup muncul secara instan di layar
                             user saat Admin menyetujui / Kepsek ttd surat.

Cara Mengaktifkan Real-Time Reverb:
  1. Buka file .env dan tambahkan variabel berikut:
       BROADCAST_CONNECTION=reverb

       REVERB_APP_ID=100001
       REVERB_APP_KEY=esurat_reverb_key
       REVERB_APP_SECRET=esurat_reverb_secret
       REVERB_HOST=127.0.0.1
       REVERB_PORT=8080
       REVERB_SCHEME=http

  2. Jalankan perintah pembersihan cache:
       php artisan config:clear

  3. Jalankan Server Reverb WebSocket di terminal tersendiri:
       php artisan reverb:start

CATATAN PENTING:
 Jika Reverb TIDAK dijalankan, pesan warning konsol browser:
 "WebSocket connection to ws://localhost:8080/ failed" adalah HAL WAJAR & AMAN.
 Seluruh fungsi aplikasi tetap berjalan 100% normal.

8. PANDUAN PENGGUNAAN LENGKAP PER PERAN (ROLE)
================================================================================

--- 8.1 GURU & KARYAWAN (Gukar) ---------------------------------------------
  A. Registrasi Mandiri (Bagi Pegawai Baru):
     1. Buka URL: http://e-surat.local/admin/register
     2. Tahap 1: Masukkan NIP Anda yang sudah ada di Master Karyawan.
     3. Tahap 2: Isi alamat email & password (min. 8 karakter + konfirmasi).
     4. Tahap 3: Periksa kecocokan data, lalu klik "Aktifkan & Daftar Akun Gukar".

  B. Mengajukan Surat Pengajuan Baru:
     1. Login ke panel ➔ Menu "Pengajuan Surat" ➔ Klik "Buat Pengajuan Surat Baru".
     2. Pilih Jenis Template Surat (Surat Tugas / Keterangan / Izin).
     3. Isi kolom variabel yang dibutuhkan (Tujuan, Keperluan, Tanggal). Data
        diri (Nama, NIP, Jabatan) terisi otomatis dari profil.
     4. Klik "Ajukan Surat". Status awal: "Menunggu (Pending)".

  C. Lacak Status & Download PDF:
     - Pantau status pada tabel atau lonceng notifikasi.
     - Setelah status berubah menjadi "Ditandatangani", klik tombol "Download PDF".

--- 8.2 ADMINISTRATOR (Admin) -----------------------------------------------
  A. Memproses Pengajuan Surat (Tahap 1):
     - Buka menu "Pengajuan Surat".
     - Klik "Setujui" ➔ Nomor surat terbuat otomatis, status menjadi "approved_admin".
     - Klik "Tolak" ➔ Masukkan alasan penolakan, status menjadi "rejected".

  B. Kelola Template Surat (No-Code Visual Builder):
     - Buka menu "Template Surat".
     - Gunakan preset instan (Surat Tugas / Keterangan / Izin) atau buat baru.
     - Format placeholder dinamis menggunakan kurung kurawal: {nama_variabel}.
     - Tentukan Kode Surat (mis. SPD, SK, SI) untuk penomoran otomatis.

  C. Import Batch Data Karyawan (Excel):
     - Buka menu "Data Karyawan" ➔ Klik tombol "Import Karyawan".
     - Unduh template Excel, isi kolom Nama, NIP, Jabatan, lalu unggah file.

  D. Pengaturan Sekolah & Kop Surat:
     - Buka menu "Pengaturan Sekolah".
     - Isi Identitas Sekolah, Nama Kepsek, NIP, serta unggah Logo & Stempel.

--- 8.3 KEPALA SEKOLAH (Kepsek) ---------------------------------------------
  A. Penandatanganan Digital (Tahap Akhir):
     - Buka menu "Pengajuan Surat" ➔ Cari surat berstatus "Disetujui Admin".
     - Klik tombol "Tandatangani Surat".
     - Sistem otomatis mencetak PDF Resmi lengkap dengan Kop Sekolah, Stempel,
       dan QR Code Keaslian. Status berubah menjadi "Ditandatangani (Signed)".

  B. Pratinjau Dokumen:
     - Klik tombol "Preview PDF" untuk memeriksa tata letak surat sebelum ttd.

10. KEAMANAN & VERIFIKASI KEASLIAN SURAT VIA QR CODE
================================================================================

1. QR Code pada PDF surat berisi URL verifikasi terenkripsi (Signed URL HMAC SHA256).
2. Memindai QR Code dengan kamera HP akan membuka Halaman Verifikasi Publik:
   http://e-surat.local/letter/verify/{uuid}?sig=...
3. Jika dokumen ASLI: Menampilkan rincian resmi nomor surat, tanggal ttd, nama
   pemohon, dan isi surat.
4. Jika QR Code dipalsukan / URL diubah: Sistem menolak dengan error 403 Forbidden.
5. Halaman verifikasi dilindungi Rate Limiting (Maksimal 60 akses/menit per IP).

11. TROUBLESHOOTING & FAQ (PEMECAHAN MASALAH)
================================================================================

  1) Error "DNS_PROBE_FINISHED_NXDOMAIN" saat buka http://e-surat.local
     Solusi: Klik 2x file `tambah_hosts.bat` di folder proyek, lalu restart Apache.

  2) Warning "WebSocket connection to ws://localhost:8080/ failed"
     Solusi: Pesan ini wajar jika Server Reverb (`php artisan reverb:start`)
     tidak dijalankan. Aplikasi tetap berfungsi normal 100%.

  3) Error "Class 'Illuminate\Foundation\Application' not found"
     Solusi: Jalankan `composer install` di terminal folder proyek.

  4) Error "ext-intl / ext-gd / ext-zip is missing"
     Solusi: Buka `C:\xampp\php\php.ini`, hapus tanda `;` pada ekstensi tersebut,
     lalu restart Apache.

  5) Error "SQLSTATE[HY000] [2002] Connection refused"
     Solusi: Buka XAMPP Control Panel, klik START pada MySQL.

  6) Error "Collation utf8mb4_0900_ai_ci not supported"
     Solusi: Ubah DB_COLLATION=utf8mb4_general_ci di `.env`, lalu
     jalankan `php artisan config:clear`.

  7) PDF tidak bisa diunduh / Storage Error 404
     Solusi: Jalankan `php artisan storage:link`.

  8) Akses via IP dari perangkat lain menampilkan DIRECTORY LISTING
     Penyebab: DocumentRoot masih mengarah ke C:/xampp/htdocs.
     Solusi: Ikuti panduan Bagian 4 untuk mengubah DocumentRoot di:
       - httpd-vhosts.conf (VirtualHost port 80)
       - httpd.conf (DocumentRoot utama)
       - httpd-ssl.conf (VirtualHost HTTPS port 443)
     Pastikan TIDAK ada "Options Indexes" di konfigurasi.
     Lalu restart Apache dari XAMPP Control Panel.

  9) Akses via IP dari perangkat lain menampilkan FORBIDDEN (403)
     Penyebab: Windows Firewall memblokir koneksi masuk Apache di
     jaringan Private, ATAU konfigurasi SSL belum diubah.
     Solusi:
       a. Buka firewall untuk Apache (lihat Bagian 4.4).
       b. Pastikan httpd-ssl.conf sudah diubah (lihat Bagian 4.3).
       c. Restart Apache dari XAMPP Control Panel.

 10) Perubahan .env atau tampilan tidak berefek
     Solusi: Bersihkan cache dengan perintah:
       php artisan config:clear
       php artisan cache:clear
       php artisan view:clear

Aplikasi E-Surat dibangun dengan arsitektur bersih yang memisahkan batas
tanggung jawab (Separation of Concerns) antara lapisan Frontend (Presentasi &
Interaksi Pengguna) dan lapisan Backend (Logika Bisnis, Data & Layanan).

Berikut adalah panduan direktori dan klasifikasi berkas aplikasi:

--------------------------------------------------------------------------------

tabel data, filter visual, live canvas interaktif, dan file styling.

1. Filament Resources & Pages (UI Admin Panel) [app/Filament/]:
   - app/Filament/Resources/LetterRequestResource.php
     -> Frontend: UI formulir pengajuan surat dinamis, badge status, tabel pengajuan.
   - app/Filament/Resources/LetterTemplateResource.php
     -> Frontend: UI Visual No-Code Template Builder surat & tabel template.
   - app/Filament/Resources/KaryawanResource.php
     -> Frontend: UI tabel data guru/karyawan, modal import Excel, form identitas.
   - app/Filament/Resources/SiswaResource.php
     -> Frontend: UI tabel siswa, modal import Excel, form biodata siswa.
   - app/Filament/Resources/UserResource.php
     -> Frontend: UI manajemen pengguna & akun login admin/kepsek/gukar.
   - app/Filament/Resources/LetterStatusLogResource.php

B. LAPISAN BACKEND (Logika Bisnis, Data Access, Otorisasi, Event, & Integrasi)
--------------------------------------------------------------------------------
Komponen yang bertanggung jawab atas proses di balik layar, penomoran otomatis,
kalkulasi data, penegakan hak akses, pembuatan dokumen PDF/QR, dan basis data.

1. Actions (Logika Bisnis Inti / Action Pattern) [app/Actions/Letter/]:
   - app/Actions/Letter/AssignNomorSuratAction.php
     -> Backend: Algoritma penomoran surat otomatis format SURAT 2025 (Nomor Urut,
        Buku Agenda Tahunan, Kode Lembaga, Kode Klasifikasi, Bulan Romawi).
   - app/Actions/Letter/GeneratePdfAndQrAction.php
     -> Backend: Pembuatan berkas PDF resmi via DomPDF dan pembentukan QR Code
        keaslian bertanda tangan digital HMAC SHA256.
   - app/Actions/Letter/BroadcastLetterStatusAction.php
     -> Backend: Pengendalian transisi status surat, pencatatan log audit, dan
        pengiriman broadcast WebSocket Reverb secara real-time.

2. Layanan & Parser Dokumen [app/Services/]:
   - app/Services/DocxTemplateParser.php
     -> Backend: Ekstraksi dan pemrosesan file Microsoft Word (.docx) dari arsip
        SURAT 2025 menjadi template HTML & variabel siap pakai.

   - app/Helpers/TemplateCompiler.php

   - app/Helpers/TemplatePresets.php
     -> Backend: Pustaka 11 template baku bawaan sekolah (Surat Tugas, SK, SPPD, dll).

   - app/Policies/UserPolicy.php           -> Backend: Otorisasi akun pengguna sistem.
